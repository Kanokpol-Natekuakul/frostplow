# FrostPlow: Cozy Snow Drifting

Cozy isometric snow-plowing game (React + three.js + Vite). Started as a Google AI Studio export (https://ai.studio/apps/8aa1ee82-26ae-4393-a0f6-3b11ea4968aa); this repo is now the source of truth. No API keys needed.

    npm install
    npm run dev    # http://localhost:3000
    npm test       # logic tests (via tsx)
    npm run lint   # typecheck
